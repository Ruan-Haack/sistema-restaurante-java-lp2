# Sistema de Autoatendimento para Restaurante

## 📖 Sobre o Projeto
Este é um sistema desenvolvido para auxiliar no atendimento aos clientes e gerenciamento de um restaurante. O projeto propõe um modelo onde o próprio cliente realiza seus pedidos através de um tablet na mesa, sem a necessidade de um garçom. 

O sistema foi desenvolvido como trabalho avaliativo da disciplina de **Linguagem de Programação II (2026.1)**, do curso da **Universidade do Estado da Bahia (UNEB)**, sob orientação da **Profa. Ana Patrícia Magalhães**. O desenvolvimento do projeto é dividido em duas etapas, contemplando a modelagem UML e a implementação completa em Java com interface gráfica.

## ⚙️ Funcionalidades

O sistema atende a três frentes principais (Gerência, Cliente e Cozinha) e inclui as seguintes funcionalidades:

**Gerenciamento (Gerente):**
* Cadastro completo (incluir, alterar, excluir e consultar) de itens do cardápio.
* Diferenciação entre cadastro de Comidas (com descrição de ingredientes) e Bebidas (com indicação do fornecedor).

**Atendimento (Cliente):**
* Cadastro de cliente contendo nome, CPF e e-mail.
* Visualização do cardápio digital via tablet.
* Abertura de conta e realização de pedidos informando as quantidades desejadas de cada item.
* Fechamento da conta com opções de pagamento via cartão de crédito ou débito.
* Sistema de fidelidade: Geração e consulta de bônus de 10% do valor consumido, que pode ser abatido no pagamento da próxima visita.

**Operação (Cozinha):**
* Visualização em tempo real dos pedidos abertos
* Opção de dar baixa (entregar pedido) quando o prato for finalizado e entregue ao cliente.
